# Presentación del grupo 3 - Diplomatura FullStack

Proyecto de presentación para la diplomatura. Es un sitio web estático que se abre directamente desde `index.html` con la información de los integrantes del grupo.

## Estructura

```
Presentacion/
├── index.html   # Página principal
├── css/         # Estilos
├── js/          # Scripts
├── img/         # Imágenes
└── data/        # Datos
```
